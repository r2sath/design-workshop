# 1. Getting Started in Figma

In this section, you will create your design file, give it a clear name, and become familiar with the main areas of the Figma interface.

## 1.1. Create a New Design File

1. Open Figma and sign in to your account.
2. From the Figma home page, create a new **Design file** from the top menu.
3. A blank Figma Design file will open.

## 1.2. Rename Your File

New Figma files are usually named **Untitled**.

1. Click the current file name near the top-left corner of the screen.
2. Rename the file:

   ```text
   Campus Café Prototype – Your Name
   ```

3. Press `Enter` to save the new name.

Giving your file a descriptive name makes it easier to find and identify later.

## 1.3. Explore the Figma Interface

Before beginning the design, locate the following parts of the Figma interface.

### Canvas

The large area in the centre of the screen is the **canvas**.

You will place your phone screens and design elements on the canvas. The canvas can extend in every direction, so you can arrange several screens beside one another.

### Layers Panel

The panel on the left side of the screen is the **Layers panel**.

It displays every frame, shape, text layer, and other object in your file. Objects placed inside a frame will appear nested underneath that frame.

You can use the Layers panel to:

- Select an object.
- Rename an object.
- Change the order of objects.
- Check whether an object is inside the correct frame.
- Hide or lock an object.

### Properties Panel

The panel on the right side of the screen is the **Properties panel**.

The available settings change depending on what you have selected. You will use this panel to adjust properties such as:

- Position and size
- Fill colour
- Text formatting
- Corner radius
- Alignment
- Auto layout
- Prototype interactions

If you do not see the setting you need, make sure the correct object is selected.

### Toolbar

The toolbar contains the main tools used to create and edit objects.

For this tutorial, you will mainly use:

| Tool | Purpose | Shortcut |
|---|---|---|
| Move | Select and move objects | `V` |
| Frame | Create phone screens and containers | `F` |
| Rectangle | Create shapes and image layers | `R` |
| Text | Add headings, labels, and descriptions | `T` |
| Hand | Move around the canvas | `H` |

You do not need to learn every tool during this tutorial.

### Design and Prototype Controls

The right sidebar includes controls for both designing and prototyping.

- Use the **Design** controls to change how an object looks.
- Use the **Prototype** controls to connect buttons and screens.

You will design all four screens first and add the prototype connections near the end of the tutorial.

### Present Button

The **Present** or **Play** button is located near the top-right corner of the screen.

You will use it later to open and test the completed café-ordering prototype.

## 1.4. Practise Navigating the Canvas

Before creating the app, practise moving around the blank canvas.

### Zoom

Use one of the following methods to zoom in or out:

- Scroll while holding `Ctrl` on Windows.
- Scroll while holding `Command` on Mac.
- Use the zoom percentage shown in the interface.
- Use a trackpad pinch gesture.

### Pan Across the Canvas

To move around the canvas without moving any objects:

1. Hold the `Spacebar`.
2. Click and drag across the canvas.
3. Release the `Spacebar` when finished.

You can also press `H` to use the Hand tool or drag while holding the middle mouse button.

### Select an Object

1. Press `V` to activate the Move tool.
2. Click the object on the canvas.

A blue outline will appear around the selected object.

You can also select an object by clicking its name in the Layers panel.

### Move an Object

1. Select the object.
2. Click and drag it to a new position.

Use the arrow keys for smaller adjustments.

### Delete an Object

1. Select the object.
2. Press `Delete` or `Backspace`.

## 1.5. Keep Your File Organized

Throughout the tutorial:

- Rename important frames and buttons.
- Keep each screen separate on the canvas.
- Check the Layers panel when an object is difficult to select.
- Make sure screen contents are nested inside the correct phone frame.
- Place reference materials beside the screens, not inside them.

You are now ready to create the colour styles and review the sample café content.
