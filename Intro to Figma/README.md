# Design Kickstarter 2026: Intro to Figma

This tutorial introduces the basic tools and workflow used to design an app interface in Figma. Students follow a guided process to create, organize, style, connect, and test the screens of a simple campus café ordering app.

The goal is not to build a fully functioning app. Instead, students will create an interactive prototype that demonstrates what the app could look like and how a user would move through it.

> **Link setup:** Replace `USERNAME` and `REPOSITORY` in the links below after the files are uploaded to GitHub.

## Project Outcome

By the end of the tutorial, students will have created a four-screen prototype that allows a user to:

1. Browse café items.
2. View an item's details.
3. Add the item to an order.
4. Review and place the order.
5. Return to the menu.

The finished prototype follows this user flow:

`Menu` → `Item Details` → `Order Summary` → `Confirmation`

## Learning Outcomes

By completing this tutorial, students will be able to:

- Navigate the main areas of the Figma interface.
- Create, name, and organize frames and layers.
- Use shapes and text to design simple app screens.
- Create and apply reusable colour and image styles.
- Adjust colours, dimensions, corner radii, alignment, padding, and spacing.
- Duplicate and reuse interface elements.
- Use auto layout to organize flexible interface elements.
- Connect screens to create an interactive prototype.
- Present and test a complete user flow.
